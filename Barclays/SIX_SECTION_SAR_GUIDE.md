# 6-Section SAR Template - Complete Implementation Guide

## Overview

Your AML system now generates professional Suspicious Activity Reports with a structured 6-section format that's compliant with FinCEN requirements and regulatory best practices.

---

## The 6 Sections

### 1. **Glossary Code**
Unique identifier and filing information for the SAR.

**Contains:**
- SAR Identification Number (auto-generated: `SAR-{alert_id}-{timestamp}`)
- Report Filing Date
- Filing Institution (Barclays Bank PLC)
- Report Status (SUBMITTED TO FinCEN)
- Reporting Officer and Regulatory Authority

**Purpose:** Provides unique tracking and filing metadata

---

### 2. **Statement of Suspicion**
Clear, concise statement of what is suspected and why filing is necessary.

**Contains:**
- Primary suspicion statement
- Confidence level (0-100%)
- Risk assessment (LOW/MEDIUM/HIGH/CRITICAL)
- Basis of suspicion (pattern analysis)
- Applicable regulations (31 U.S.C. § 5318(g))

**Purpose:** Establishes legal basis for SAR filing

---

### 3. **Customer Details**
Complete information about the customer involved in the suspicious activity.

**Contains:**
- Customer Name
- Customer ID and Account Number
- Account Type
- Account Status and KYC Status
- Address, Phone, Email
- Risk Rating
- Enhanced Due Diligence requirement

**Purpose:** Identifies the customer and KYC compliance status

---

### 4. **Description of Suspicion**
Detailed analysis of the suspicious activity covering all aspects.

**Contains:**
- Transaction Details (date, amount, currency, type)
- Patterns Detected (fraud patterns identified)
- Behavioral Anomalies
- Unusual Behaviors
- Frequency Analysis
- Geographic Destination Analysis

**Purpose:** Provides comprehensive activity documentation

---

### 5. **Core Error/Operation Analysis**
Deep dive into the primary suspicious operation (especially for cryptocurrency).

**Contains:**
- Core Suspicious Operation Type
- Operation Analysis
- **For Cryptocurrency Cases:**
  - Type of cryptocurrency (Bitcoin, Ethereum, etc.)
  - Purchase method and platform
  - Wallet addresses (source and destination)
  - Holding period
  - Transfer patterns
  - Use of mixing services
  - Final destination
  - Red flags in crypto movement
- Regulatory Violations

**Purpose:** Explains the core mechanism of the suspected financial crime

---

### 6. **Summary and Recommendations**
Executive summary with risk assessment and recommended actions.

**Contains:**
- Summary of findings
- Risk Assessment (Inherent, Control, Detection, Net)
- Recommended Actions:
  1. Freeze account (if warranted)
  2. File CTR if threshold exceeded
  3. Enhanced due diligence
  4. Review related accounts
  5. Coordinate with law enforcement
  6. Maintain documentation
  7. FinCEN escalation
- Filing Information (status, date, approval)

**Purpose:** Provides actionable next steps for compliance

## API Endpoints

### Generate SAR (Text Format)
```bash
POST /api/generate-sar
Content-Type: application/json

{
  "alertId": 123
}

Response:
{
  "sar_text": "[Full 6-section SAR text]",
  "sections": {
    "1": "[Glossary Code content]",
    "2": "[Statement of Suspicion]",
    "3": "[Customer Details]",
    "4": "[Description of Suspicion]",
    "5": "[Core Operation Analysis]",
    "6": "[Summary]"
  },
  "template": "six_section_sar",
  "status": "success",
  "metadata": {
    "total_sections": 6,
    "confidence": 87.5,
    "risk_level": "HIGH",
    "patterns": ["Structuring", "Rapid Transfers"]
  }
}
```

### Generate SAR (PDF Format - Beautiful Professional Format)
```bash
POST /api/generate-sar-pdf
Content-Type: application/json

{
  "alertId": 123
}

Response: Binary PDF file
Content-Type: application/pdf
Content-Disposition: attachment; filename="SAR_123_1711689600000.pdf"
```

## Section Content Generation

### Enhanced RAG System
Each section is automatically generated by the **EnhancedRAGSystem** which:

1. **Analyzes the alert** for fraud patterns, confidence scores, risk levels
2. **Retrieves regulatory context** from knowledge base
3. **Generates section-specific content** based on alert characteristics
4. **Detects cryptocurrency activity** and includes special crypto analysis
5. **Applies compliance rules** for timing and thresholds

### Cryptocurrency Special Handling

When cryptocurrency is detected in patterns (e.g., "Cryptocurrency Mixing"):

**Section 5 expands to include:**
- Cryptocurrency type (Bitcoin/Ethereum/etc)
- Purchase exchange and amount
- Receiving wallet type (personal/exchange/mixer/privacy-enhanced)
- Mixing service indicators (CoinJoin, Tornado Cash)
- Hop count through intermediaries
- Privacy coin use (Monero, Zcash)
- Travel Rule violations
- OFAC compliance concerns

## Example: Structuring Case

**Input Alert:**
```
{
  "alert_id": 42,
  "account_id": "ACC-001",
  "confidence_score": 92,
  "risk_level": "HIGH",
  "patterns_detected": ["Structuring", "Rapid_Transfers"],
  "amount_paid": 9900,
  "customer_name": "John Smith"
}
```

**Generated SAR Output:**

```
SECTION 1: GLOSSARY CODE
========================
SAR Identification Number: SAR-42-1711689600000
Report Filing Date: 2026-03-29
Filing Institution: Barclays Bank PLC
Report Status: SUBMITTED TO FinCEN

SECTION 2: STATEMENT OF SUSPICION
==================================
Barclays Bank PLC has reasonable suspicion that the following 
transaction(s) may involve money laundering and terrorist financing.

Primary Suspicion: Structuring, Rapid Transfers
Confidence Level: 92% (Very High Probability)
Risk Assessment: HIGH RISK
Basis: Pattern analysis consistent with 31 U.S.C. § 5324

SECTION 3: CUSTOMER DETAILS
============================
Customer Name: John Smith
Customer ID: ACC-001
Account Type: Standard Checking
Account Status: ACTIVE

SECTION 4: DESCRIPTION OF SUSPICION
====================================
Transaction Date: 2026-03-29
Transaction Amount: $9,900 USD
Patterns: Multiple deposits just below reporting threshold
Behavioral Anomalies: Deliberate structuring to avoid CTR

SECTION 5: CORE ERROR/OPERATION ANALYSIS
=========================================
Core Suspicious Operation: Structured Deposits Below Reporting Threshold
Analysis: Transaction exhibits money laundering characteristics
Primary Violation: 31 U.S.C. § 5324 (Structuring)

SECTION 6: SUMMARY AND RECOMMENDATIONS
=======================================
Summary: Account demonstrates clear structuring pattern
Risk Assessment: CRITICAL
Recommended Actions:
1. IMMEDIATE: Freeze account pending investigation
2. File Currency Transaction Report
3. Conduct enhanced due diligence
4. Escalate to FinCEN
```

## Usage Workflow

```
1. Alert Generated by ML Service
        ↓
2. Frontend displays alert to analyst
        ↓
3. Analyst clicks "Generate SAR"
        ↓
4. Backend calls /api/generate-sar
        ↓
5. EnhancedRAGSystem generates 6 sections
        ↓
6. Sections formatted as text OR PDF
        ↓
7. Analyst reviews and submits to FinCEN
        ↓
8. SAR filed with 30-day compliance
```

## Compliance Notes

🔒 **FinCEN Compliance:**
- SARs must be filed within 30 days of detection
- Contains "No Tipping Rule" compliance statement
- Minimum threshold: $5,000 USD
- All records retained for minimum 5 years

📋 **Regulatory Basis:**
- Bank Secrecy Act (31 U.S.C. § 5318)
- Suspicious Activity Reporting Rule
- Know Your Customer (KYC) Requirements
- Currency Transaction Report (CTR) Rules
